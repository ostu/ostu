**Старший продуктовый аналитик · Analytics Engineer · Разработка продуктов с помощью ИИ**

Использую ИИ-агентов для ускорения разработки, сохраняя за собой контроль над требованиями, архитектурой, проверкой результатов и решениями о выпуске. Некоторые из представленных проектов начинались как аналитические системы, созданные вручную; другие с самого начала разрабатывались с помощью ИИ.

## Мой подход

Мне интересны проекты, в которых **цифры можно объяснить, логику — проверить, а результат приносит практическую пользу**. Поэтому я документирую допущения, сверяю новые расчёты с предыдущими, исключаю конфиденциальные данные из публичных материалов и обозначаю границы фактически проведённых измерений.

В представленных репозиториях опубликован либо **общедоступный исходный код** (CS2 Tournament Analytics, My Garden), либо **технические кейсы с реальными скриншотами** (Dance Card, Туристу, Wizard Tower). Закрытые репозитории с исходным кодом намеренно не публикуются.
